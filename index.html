访问方式

GitHub Pages 在线访问

启用 Pages 后，可以直接访问仓库首页站点，并从首页进入两个主题图谱。如果 Pages 发布成功，项目地址将是：https://beckshuai.github.io/awesome_knowledge/

本地浏览器预览

推荐通过本地静态服务器打开，而不是直接双击 HTML。因为页面内部通过 fetch 加载 JSON 数据，需要 HTTP 访问环境。

本地运行示例

在仓库根目录执行：
cd "/Users/bytedance/repos/github/awesome_knowledge"
python3 -m http.server 8000
然后在浏览器打开：http://localhost:8000
