项目入口说明

除了在线访问，也可以从本地直接运行整个仓库根目录，把首页作为统一入口。

GitHub Pages 在线访问

首页站点地址为 https://beckshuai.github.io/awesome_knowledge/。从这里可以继续进入孩子教育图谱和经济学图谱两个子站。

本地浏览器预览

推荐通过静态服务器打开仓库根目录，而不是直接双击 HTML 文件。因为图谱页面内部通过 fetch 加载 JSON 数据，需要 HTTP 环境。

未来图谱目录

这是首页新增的“未来图谱目录”区域，用来明确后续计划主题，让整个站点从“已上线内容”扩展为“持续演进的知识图谱站”。

本地运行示例

把仓库根目录作为静态站点根目录，就可以直接从首页进入所有图谱。
在仓库根目录执行：
cd "/Users/bytedance/repos/github/awesome_knowledge"
python3 -m http.server 8000
然后在浏览器打开：http://localhost:8000
