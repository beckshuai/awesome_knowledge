本地浏览器预览

推荐通过静态服务器打开仓库根目录，而不是直接双击 HTML 文件。因为图谱页面内部通过 fetch 加载 JSON 数据，需要 HTTP 环境。

本地运行示例

把仓库根目录作为静态站点根目录，就可以直接从首页进入所有图谱。
在仓库根目录执行：
cd "/Users/bytedance/repos/github/awesome_knowledge"
python3 -m http.server 8000
然后在浏览器打开：http://localhost:8000
